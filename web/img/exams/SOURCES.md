# Candidate image sources (Radiopaedia)

Normal-anatomy MRI cases for each image-library part, mapped to its folder slug.
These are grayscale "normal" reference cases — good for clean scout/example images.

**Before using any image:**
- Save images **manually** (right-click → Save image). Do *not* bulk-scrape — Radiopaedia's
  Terms of Use forbid automated downloading, even though the images themselves are CC BY-NC-SA 3.0.
- Record the **author + case URL** for each image you keep (shown on the case page as
  "Case courtesy of …"). You need it for attribution.
- Usage must stay **non-commercial**, keep **attribution**, and adaptations stay **share-alike**
  (CC BY-NC-SA 3.0). See [`README.md`](README.md) for the licensing note.
- Not every case has all 3 planes × every sequence — grab what's there, name per the README,
  and missing files just keep showing the placeholder.

## Other free sources

- **Wikimedia Commons** — public-domain / CC. Strong for brain & knee, thin for the parts above.
  Good knee reference: [Knee MRI T1 TSE Sagittal](https://commons.wikimedia.org/wiki/File:Knee_MRI_T1_TSE_Sagittal.jpg).
- **TCIA** (cancerimagingarchive.net) — CC-BY DICOM datasets; export your own slices for the
  cleanest licensing.
